## 3) Engagement Design Patterns

### Infinite Scroll
Continuous content loading to reduce stopping points.

### Personalization Loop
Use watch time, likes, shares, search behavior, and follows to continuously rerank feed results.

### Fast Reward Signals
Frequent micro-rewards:
- likes
- follows
- comments
- mentions

### Social Validation
Visible metrics (likes/views/followers) to reinforce posting behavior.

### Variable Reward Schedule
Unpredictable quality distribution in feed increases return scrolling behavior.

### Creator Growth Loop
Post -> engagement -> algorithm boost -> followers -> more posting.

## Final Platform Shape
- Home feed (AI ranking)
- Explore (discovery)
- Create (production + upload)
- Messages (communication)
- Profile (identity + creator hub)
